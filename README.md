### Inteligencia Artificial & Automatización
* **LLMs & Agentes:** Arquitecturas *Architect/Editor*, análisis estático de código (AST) para compresión de contexto, RAG avanzado, integración de APIs cloud y despliegues locales (`vLLM`, `Ollama`).

* **Continuidad de Negocio:** Sistemas de respaldo automatizados **3-2-1** deduplicados y cifrados (`Restic`, `Rclone`, `Systemd Timers`, `rsync`).
* **CI/CD & Flujo de Trabajo:** Git (estrategias de despliegue seguro y trunk-based/release branching), GitHub Actions, GitHub CLI (`gh`), gestión de entornos reproducibles con `uv`.

### Frontend de Alto Impacto

* **Enfoque:** Carga instantánea (`0.0s` percibidos), arquitecturas *offline-first*, diseño orientado a conversión cualificada y experiencias visuales fluidas.

## 🚀 Proyectos Públicos Destacados (Open Source / Demos Técnicas)

Aunque la mayor parte de mi trabajo se encuentra bajo acuerdos de confidencialidad (NDA) y propiedad intelectual para clientes, mantengo repositorios públicos con herramientas de ingeniería interna y pruebas de concepto:

* **[`double-agent`](https://github.com/andres885/double-agent):** Optimizador de contexto para LLMs pesados basado en el patrón *Architect/Editor*. Utiliza análisis AST y modelos locales para reducir el consumo de tokens entre un **85% y un 95%** en bases de código grandes, aplicando parches deterministas en disco.
* **[`weather-alpha`](https://github.com/andres885/weather-alpha):** Plataforma de trading cuantitativo y ejecución táctica en tiempo real sobre mercados de predicción (CLOB L2). Construida con FastAPI, XGBoost, PostgreSQL/TimescaleDB y Docker.
* **[`web-extractor`](https://github.com/andres885/web-extractor):** Microservicio en FastAPI + Playwright basado en el paradigma *Set-of-Mark (SoM)* para extracción web estructurada e inyección de *bounding boxes* orientadas a agentes de visión.
* **[`backup-system-3-2-1`](https://github.com/andres885/backup-system-3-2-1):** Arquitectura de recuperación ante desastres automatizada en cascada para servidores Debian, con deduplicación y cifrado mediante Restic, Rclone y Systemd Timers.
* **[`ffmpeg-gui`](https://github.com/andres885/ffmpeg-gui):** Aplicación de escritorio multiplataforma (Linux, Windows, macOS) desarrollada en **Rust y Tauri v2** para recodificación y optimización automatizada de vídeo con CI/CD en GitHub Actions.
* **[`transcriptor`](https://github.com/andres885/transcriptor) & [`voice-assistant`](https://github.com/andres885/voice-assistant):** Herramientas de procesamiento acústico con FFmpeg, transcripción en lote e inyección de voz offline en tiempo real en Linux utilizando Whisper y aceleración por hardware (`CUDA`).
