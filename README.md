## 🛠️ Stack Tecnológico & Arquitectura

### Inteligencia Artificial, Voz & Gráficos 3D
* **Gráficos 3D & Motores en Tiempo Real:** Blender (modelado realista, baking, retopología y optimización extrema de assets para tiempo real), integración WebGL / 3D en navegador, LibGDX (Java).
* **LLMs & Agentes Web:** Arquitecturas *Architect/Editor*, integración de agentes conversacionales y de navegación en interfaces web, análisis estático de código (AST) para compresión de contexto, despliegues en cloud y locales (`vLLM`, `Ollama`).
* **Multimodal, Audio & Visión:** OpenAI Whisper / `whisper.cpp` con aceleración por hardware (`CUDA`), extracción visual estructurada (*Set-of-Mark* con Playwright), entrenamiento y ajuste fino de modelos generativos de última generación.

### Backend, Sistemas & Datos
* **Lenguajes:** Python (Asyncio, FastAPI), PHP 8.4+ (Arquitectura nativa de alto rendimiento), Rust (Tauri v2), Java, Bash / Shell Scripting.
* **Bases de Datos:** PostgreSQL, TimescaleDB (series temporales), MariaDB / MySQL (optimización extrema de consultas e índices).
* **Ciencia de Datos & Quant:** XGBoost, NumPy, SciPy, Pandas, motores de inferencia probabilística y ejecución táctica en tiempo real sobre libros de órdenes (CLOB).

### DevOps, Seguridad & Infraestructura
* **Entornos & Red:** Debian GNU/Linux, Docker & Docker Compose, Apache / Nginx tuning, gestión avanzada de red, proxies rotatorios, WireGuard, OpenSSL/Certbot.
* **Continuidad de Negocio:** Sistemas de respaldo automatizados **3-2-1** deduplicados y cifrados (`Restic`, `Rclone`, `Systemd Timers`, `rsync`).
* **CI/CD & Flujo de Trabajo:** Git, GitHub Actions, GitHub CLI (`gh`), gestión de entornos reproducibles con `uv`.

### Frontend de Alto Impacto
* **Tecnologías:** JavaScript (ES6+ Vanilla), React, HTML5 semántico, CSS3 / SASS avanzado, Web Components nativos.
* **Enfoque:** Carga instantánea (`0.0s` percibidos), renderizado fluido a 60 FPS, arquitecturas *offline-first* y diseño orientado a conversión cualificada.
